# ___Документация по модулям EnglishCard___
---
## ___Модуль main.py___
- Библиотеки
- Вызов основных функций
  - Функция отрисовки сайта 
  - Функция вызова БД
## ___Модуль bd_manager.py___
- Библиотеки
- Класс работы с БД
## ___Модуль site_view.py___
- Библиотеки
- Функции отрисовки внешнего вида сайта
- Взаимодействие БД и интерфейса кнопок сайта
## ___Модуль documentation.py___
- Функции вызова документации из интерфейса сайта
## ___Модуль translater.py___
- Содержит в себе вызов API Yandex словаря
- токен необходимо указать в файле .env пример в .env.example
- [Ссылка](https://yandex.com/dev/dictionary)
> Если нет токена перейдите по ссылке и следуйте инструкции 
## ___Модуль get_photos_dog_random.py___
- Содержит в себе вызов API Dog.ceo
> Пользователь в качестве награды за правильный ответ будет видеть картинку собаки<br>
> Всегда возвращается рандомная картинка
## ___Модуль super_hero_api.py___
- Содержит в себе логику работы с api по героям 
> используется в 3 тренажере 
> 3-ий тренажер не привязан в данный момент к БД сделал его , уже после основного проекта.
## ___Модуль GET_IP.py___
- содержит в себе вызов API ipify
- Нужен токен для работы его можно получить по ссылке [ссылка](https://www.ipify.org)  
> указываем токен в файле .env пример в файле .env.example
