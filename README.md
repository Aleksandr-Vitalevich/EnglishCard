# ___Документация по модулям EnglishCard___
---
## ___Модуль main.py___
- Библиотеки
- Вызов основных функций
  - Функция отрисовки сайта 
  - Функция вызова БД
## ___Модуль bd_manager.py___
- Библиотеки
- Класс работы с БД
## ___Модуль site_view.py___
- Библиотеки
- Функции отрисовки внешнего вида сайта
- Взаимодействие БД и интерфейса кнопок сайта
## ___Модуль documentation.py___
- Функции вызова документации из интерфейса сайта
## ___Модуль translater.py___
- Содержит в себе вызов API Yandex словаря
## ___Модуль get_photos_dog_random.py___
- Содержит в себе вызов API Dog.ceo
> Пользователь в качестве награды за правильный ответ будет видеть картинку собаки<br>
> Всегда возвращается рандомная картинка
### ___Дополнительная информация___
- Фото Курсовая.drawio.png -> схема бд. 
- Файл words_first_data.json -> содержит первые 15 слов для автоматического наполнения бд. 
- Файл .streamlit. Файл содержит в себе настройки цветов интерфейса. Эту настройку делал когда изучал фреймворк, ИИ помог. 
- Реализовано разграничение меню обычного пользователя и root пользователя . 
- Добавлено автоматическое создание пользователя root 
- Попытался разграничить функционал 
  - Пользователи могут добавлять себе слово или удалять его , но только из своего личного кабинета , функционал добавления и удаления завязан на кнопке изучения
  - root может добавлять и удалять пользователей, слова в базе данных
- Реализована возможность просмотра документации из веб интерфейса
- Файл .env в нем содержаться настройки БД и Токен от yandex dictionary
