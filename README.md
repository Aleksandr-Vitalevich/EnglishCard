# ___EnglishCard — Изучай английский с удовольствием! (v2.0)___
---

## Глобальное обновление архитектуры: Переход на Версию 2.0

В версии 2.0 проект прошёл полную стадию тотального рефакторинга. Исходный монолитный код был распилен на изолированные пакеты и модули, что снизило нагрузку на главный файл интерфейса `site_view.py` **почти в 7 раз (с 800 до 116 строк кода!)**. Проект избавился от «кода-призраков», стал легко читаемым, масштабируемым и полностью готовым к командной разработке.

---

## Список ключевых изменений и нововведений (Changelog)
---
### 1. Переход на Пакетную Архитектуру 
Вся логика приложения строго распределена по специализированным пакетам (каждая папка содержит `__init__.py` для управления экспортом):
*   `db_manager/` — бэкенд базы данных. Разделён на `config.py` (динамические пути и `.env`), `models.py` (декларативные ORM-таблицы SQLAlchemy) и `bd_manager.py` (бизнес-логика класса `BD_MANAGER`).
*   `api_services/` — стерильные модули интеграции с внешними API (Переводчик, Яндекс.Диск, API Супергероев, API Собак,и логирование Гео-IP), работающие «на лету».
*   `utils/` — системные утилиты, функции безопасности (`bcrypt`).
*   `view/` — чистый фронтенд. Разделён на модули авторизации, меню и специализированные подпакеты функций.

### 2. Новый Парадигма Симуляторов Обучения (`view/simulators/`) 
Самый громоздкий блок «Изучение» (более 370 строк кода) был полностью изолирован. Управление тренажёрами переведено с бесконечных веток `if/elif` на быстрый и читаемый `match case` внутри главного оркестратора `sim_dispatcher.py`. Каждый тренажёр вынесен в свой файл с понятным неймингом вместо безликих цифр:
*   `sim_variants.py` — тест с выбором из 4-х вариантов.
*   `sim_writing.py` — письменный тест на ввод перевода слова.
*   `sim_heroes.py` — тренажёр по супергероям (интеграция с API, загрузка картинок в байтах, озвучка `gTTS`).
*   `sim_dogs.py` — тренажёр по породам собак.

### 3. Бронебойная Логика Путей и Изоляция Кэша (`media_cache/`) 
*   Внедрён **динамический расчёт абсолютных путей** через модуль `os.path`. Проект больше не привязан к конкретным папкам на диске — его можно запускать с флешки или переносить на Linux/macOS без изменения кода.
*   Все временные файлы (кэш аудио `.mp3`, скачанные через API JSON-файлы, вроде списка супергероев) теперь принудительно сохраняются в выделенную папку-изолятор `media_cache/`. Корень проекта полностью очищен от мусора и защищён файлом `.gitignore`.

### 4. Продвинутая Панель Администратора PostgreSQL 
Админка `root` превратилась в полноценный Web Dashboard для управления СУБД:
*   Все административные фичи (`add_word`, `delete_word`, `add_user`, `delete_user`, `show_users`) вынесены в отдельный пакет `view/root_functions/`.
*   Кнопки меню в интерфейсе генерируются динамически в зависимости от роли вошедшего пользователя благодаря новому модулю `view/menu_config.py`.

### 5. Интерактивный Центр Документации на `inspect` 
*   Полностью переписан экран документации в пакете `documentation/`. Логика разделена на два независимых экрана: интерактивная схема БД (слайдер-карусель Bootstrap со спойлерами `st.expander` истории изменений структуры) и автоматический сканер кода.
*   Реализован **динамический сканер архитектуры** на базе встроенной библиотеки Python `inspect`. Система полностью избавилась от ручного хардкода списков из десятков функций. Админ просто выбирает пакет, а Python на лету сканирует его методы и выводит документацию из docstrings (`"""Текст"""`).

### 6. Железобетонное Управление Сессиями и Безопасность 
*   Внедрён полный и безопасный сброс сессий (`st.session_state`) напрямую в обработчике кнопки «Выход» в `st.sidebar`. Это полностью уничтожило баг «призраков кода», когда данные прошлых сессий оставались видны при повторном входе.
*   Все секретные токены (Яндекс.Диск, СУБД) полностью удалены из тела главного файла `main.py` и инкапсулированы внутри использующих их модулей с подтягиванием через `.env`.
